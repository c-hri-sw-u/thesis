# 037: MyLifeBits: A Personal Database for Everything

**Authors:** Jim Gemmell, Gordon Bell, Roger Lueder

**Year:** 2006 (Communications of the ACM, Vol. 49, No. 1)

**Topics:** 2.5 (Egocentric Vision and Self-Logging)

**Source:** Microsoft Research

---

## Summary

MyLifeBits is a pioneering lifelogging project from Microsoft Research that aimed to fulfill Vannevar Bush's Memex vision of a personal database storing all of an individual's digital information. This seminal work laid the foundation for modern personal informatics and self-logging systems.

### Key Contributions

1. **Comprehensive Personal Database**: Designed a system to store:
   - Scanned documents (articles, books, papers)
   - Digital photographs
   - Email correspondence
   - Web browsing history
   - Phone calls and voice recordings
   - Television and radio consumption
   - IM transcripts

2. **Technical Innovations**:
   - Database schema optimized for personal multimedia data
   - Metadata tagging and annotation system
   - Search and retrieval mechanisms
   - Storage cost analysis (projected costs declining rapidly)

3. **Experimental Validation**: Gordon Bell used himself as a test subject:
   - Scanned all physical documents
   - Recorded all digital communications
   - Wore a SenseCam for passive photo capture
   - Demonstrated feasibility of "lifelogging"

4. **Vision for Personal Memory**: Explored how such a system could:
   - Augment human memory
   - Support knowledge work
   - Enable personal analytics
   - Preserve personal history

### Relevance to Personal AI Agents

This paper is foundational for personal AI agents in several ways:

1. **Data Foundation**: MyLifeBits shows what data a personal agent could access:
   - Communications history
   - Document corpus
   - Activity patterns
   - Media consumption

2. **Storage Architecture**: Demonstrates database design for personal data:
   - Multiple media types
   - Rich metadata
   - Temporal indexing
   - Cross-referencing

3. **User Interface Challenges**: Highlights the need for:
   - Effective search
   - Visualization tools
   - Context presentation
   - Privacy controls

4. **Historical Context**: Provides the vision that modern personal agents are beginning to fulfill

### Key Insights for Thesis

- **Data Collection**: Shows the breadth of data that can be collected about a person's life
- **Storage Challenges**: Addresses how to organize and index personal information
- **Retrieval Problem**: Identifies the challenge of finding relevant information in a lifetime of data
- **Human Memory Augmentation**: Demonstrates the potential for AI to enhance human memory
- **Privacy Implications**: Early recognition of privacy concerns in personal data collection

### Connection to Modern Systems

MyLifeBits can be seen as a precursor to:
- Modern personal knowledge management systems (Obsidian, Notion)
- Lifelogging apps and devices
- Personal AI assistants that access user data
- Digital legacy and archival systems
