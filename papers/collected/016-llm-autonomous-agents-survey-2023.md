# 016: A Survey on Large Language Model based Autonomous Agents

**Authors:** Lei Wang, Chen Ma, Xueyang Feng, Zeyu Zhang, Hao Yang, Jingsen Zhang, Zhiyuan Chen, Jiakai Tang, Xu Chen, Yankai Lin, Wayne Xin Zhao, Zhewei Wei, Ji-Rong Wen

**Year:** 2023 (arXiv:2308.11432, last revised March 2025)

**Topics:** 2.1 (From LLM-Based Agents to Personal AI Agents)

---

## Summary

This comprehensive survey provides a unified framework for understanding LLM-based autonomous agents. The authors systematically review the architecture, applications, and challenges of autonomous agents powered by large language models.

### Key Contributions

1. **Unified Framework**: Proposes a general architecture for LLM-based autonomous agents consisting of:
   - Agent brain (LLM core)
   - Perception module
   - Action/execution module
   - Memory system

2. **Comprehensive Taxonomy**: Categorizes existing work along multiple dimensions:
   - Agent architecture patterns
   - Planning and reasoning strategies
   - Memory mechanisms
   - Tool use and action execution

3. **Application Domains**: Reviews applications across:
   - Web navigation
   - Software development
   - Scientific research
   - Game playing
   - Robotics

### Relevance to Personal AI Agents

This survey provides the foundational understanding of how autonomous agents work, which is essential for building personal AI agents. The framework helps understand:
- How to structure a personal agent system
- Memory architectures for long-term personalization
- Integration of perception and action for embodied agents
- Planning and reasoning for personal tasks

### Key Insights for Thesis

- **Architecture Foundation**: The unified framework informs the architecture design for personal AI agents
- **Memory Importance**: Highlights the critical role of memory systems for agent coherence
- **Tool Use**: Shows how agents can extend capabilities through tool integration
- **Challenges**: Identifies open problems in reliability, safety, and evaluation
