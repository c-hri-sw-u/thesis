# 044 - ACT-R: A Theory of Higher Level Cognition (1997)

**Authors:** John R. Anderson, Michael Matessa, Christian Lebiere

**Source:** Human-Computer Interaction, Volume 12, Issue 4, Pages 431-469

## Summary

This paper presents ACT-R as a cognitive architecture designed for modeling a wide range of higher level cognitive processes. The authors describe ACT-R as consisting of multiple specialized modules (perceptual-motor, goal, declarative memory, and production) that are integrated to produce coherent cognition. The architecture is built on the principle of activation-based processing, where the accessibility of knowledge items in memory depends on their activation levels, which are influenced by factors such as recency, frequency, and associative context. A key contribution is the theory of how higher level cognitive processes interact with visual attention, providing a unified framework for understanding cognitive task performance. The paper demonstrates ACT-R's application to menu selection tasks, showing that the theory makes unique predictions about search time without parameter estimation, and these predictions are empirically confirmed. ACT-R serves as both a computational model of human cognition and a theory of intelligent behavior, enabling predictions about human performance in human-computer interaction contexts.

## Key Contributions

- Modular cognitive architecture with specialized components
- Activation-based memory model with declarative and production systems
- Theory of visual attention integrated with higher-level cognition
- Empirical validation through menu selection experiments
- Framework for predicting human-computer interaction performance

## Relevance to Thesis

This paper is crucial for Section 2.3 (Memory Architectures), providing the foundational theory of activation-based memory systems and modular cognitive architectures. ACT-R's activation model directly informs how memory retrieval and attention mechanisms operate in intelligent systems.
